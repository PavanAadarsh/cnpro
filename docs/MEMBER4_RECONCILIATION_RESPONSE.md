## 2. Automatic Syslog Event Collector & Dual Ingestion Contract

### 2.1 Implemented & Fully Operational Syslog Collector (`event_listener.py`)
To satisfy the automatic detection requirement beyond CLI injection, Member 3 has implemented [`policy_engine/event_listener.py`](../policy_engine/event_listener.py) which exposes a live UDP service on `POLICY-HOST`:
- **UDP Port 514 (Syslog):** Ingests Cisco IOS syslog packets generated by CORE-SW ACL deny rules (`deny ip any any log` triggering `%SEC-6-IPACCESSLOGP` messages).
- **IP-to-Device Resolution:** Matches the logged source IP to the offending endpoint (e.g., `192.168.10.x` $\rightarrow$ `PC-STU1`/`PC-STU2`).
- **Pattern Matcher:** Parses access violations, brute-force auth failure alerts, and port scans, directly feeding them into `PolicyEngine.handle_event(device, event_type)`.

### 2.2 How to Run the Automated Daemon
From `POLICY-HOST` (`192.168.40.50`):
```powershell
python simulate_event.py listen --port 514 --interval 30
```
*This runs the live Syslog listener and simultaneously triggers the autonomous background recovery thread every 30 seconds.*

### 2.3 Explicit Dual-Environment Clarification
- **In Cisco Packet Tracer:** Cisco Packet Tracer simulated switches and PCs do not emit external UDP syslog datagrams to outside hosts. Therefore, in Packet Tracer, **the Manual Event Injection contract** (`python simulate_event.py event <DEVICE> <EVENT_TYPE>`) is the intended and supported mechanism.
- **In GNS3 / Physical Rig / Python Mock:** The **Automatic Syslog Listener** (`event_listener.py`) is fully functional and tested (`tests/test_event_listener.py`).

## 4. Supported Lab Setup for Switch Enforcement & Address Renewal

### 4.1 SSH Enforcement Pipeline
1. **Control Host:** `POLICY-HOST` (`192.168.40.50`, VLAN 40, `ACCESS-SW-A` port `Fa0/7`).
2. **Target Switch Reachability:**
   - `CORE-SW`: `192.168.40.1` (VLAN 40 SVI)
   - `ACCESS-SW-A`: `192.168.40.21` (VLAN 40 SVI)
   - `ACCESS-SW-B`: `192.168.40.22` (VLAN 40 SVI)
3. **Credentials:** `username admin privilege 15 secret Admin@123`
4. **IOS Command Sequence pushed via Paramiko `invoke_shell()`:**
   ```ios
   configure terminal
   interface <target-port>
    switchport access vlan <60|70|home_vlan>
   end
   write memory
   ```

### 4.2 Switchport VLAN Verification
To independently verify that the port was reassigned on `ACCESS-SW-A` or `ACCESS-SW-B`:
```ios
show interfaces FastEthernet0/X switchport | include Access Mode VLAN
```
Or view the entire status table:
```ios
show interfaces status
```

### 4.3 Endpoint Address Renewal Workflow
When a port's VLAN is switched (e.g. from VLAN 10 to VLAN 60 or 70):
1. **In Real OS / GNS3:** The link flap or DHCP lease expiry causes the OS DHCP client to initiate a `DHCPDISCOVER`.
2. **In Cisco Packet Tracer:** Packet Tracer PC endpoints maintain existing IP bindings until renewed. The verified operator command sequence on the target PC Command Prompt is:
   ```cmd
   ipconfig /release
   ipconfig /renew
   ipconfig
   ```
   *Expected outcome:* The PC obtains an IP address in the range `192.168.60.100–254` (for RESTRICTED) or `192.168.70.100–254` (for QUARANTINE).
