### Findings requiring team attention

1. **S12 is inconsistent:** student→admin ICMP echo is permitted by an earlier
   broad ICMP rule, despite the documented DENY/PASS. No rule was changed.
2. **Admin internet permissions are narrower than the matrix:** TCP/25 to
   INTERNET-SRV is denied, despite its "all ports" statement.
3. Engine state name is **QUARANTINE**. Requested state/current_vlan still change
   on SSH failure; the adapter preserves enforcement_failed and never treats the
   JSON state alone as effective isolation/restoration.
4. Repeated `policy_violation` alone leaves NORMAL unchanged. A real detector must
   supply the appropriate event, e.g. two cross_vlan_attempt events/600 s. No
   automatic ACL-drop detector is delivered by either branch.
5. Remediation flag does not bypass the actual 30/120-minute hold, despite broader
   descriptions in some Member 3 documentation. Manual admin clear is immediate.
6. VLAN50 contains a broad final server-subnet permit. Same-VLAN management
   traffic may bypass the core routed ACL; neither point was silently rewritten.
7. Member 3 design prose describes a 60-second auth window and remediation access
   in quarantine; actual Python uses 300 seconds and Member 2's VLAN70 ACL denies
   remediation. The add-on follows actual code/rules and flags the prose for review.
